How to use this plan

  • Your advantage: As IT user support you already troubleshoot, document, and communicate with users — core DevOps skills.
  • Daily rhythm: Read/watch (30 min) → hands-on lab (60–90 min) → write 3 bullet notes in a learning journal.
  • Free tools: Linux VM (VirtualBox), Docker Desktop, GitHub free tier, AWS free tier or Azure free credits.
  • Germany focus: Learn GDPR basics, document in English (most DevOps jobs) and practice German tech vocabulary for interviews.
  • Job target: Junior→Intermediate DevOps Engineer, Platform Engineer, or Cloud Engineer (€45k–€65k typical entry in DE).

After week 8 — keep going

  • Prepare for CKA (Kubernetes) or AWS Solutions Architect Associate — both valued in Germany.
  • Contribute to open-source DevOps repos on GitHub.
  • Update LinkedIn/XING with your capstone project and link the public repo.
  • Apply to: Mittelstand companies, startups, consultancies (Accenture, Capgemini), and remote EU roles.
  • Join local meetups: DevOps Berlin, Cloud Native Munich, or virtual CNCF meetups.
