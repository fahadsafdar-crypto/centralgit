# IT-Administrator Stellenanzeige

Landingpage zum Anforderungsprofil **IT-Administrator (m/w/d)** für ein IT-Systemhaus in Speyer.

## Inhalt

- Rolle und Zielgruppe (Berufseinsteiger und erfahrene Admins)
- Gehaltsspanne 40.000 € – 60.000 €
- Technische Schwerpunkte (Windows Server, Azure, M365, AD, VEEAM, Firewall, Switch, Telefonanlagen)
- CTA für ein kurzes Telefonat inkl. Terminvorschläge

## Lokal öffnen

Statische Seite — einfach `index.html` im Browser öffnen oder einen lokalen Server starten:

```bash
python3 -m http.server 8080
```

Danach unter [http://localhost:8080](http://localhost:8080) aufrufen.
