# DevOps study pages

Static HTML. No install, no backend. State stays in your browser (`localStorage`).

## Revision + interview notebook (use this to study)

Open **`devops-revision-interview.html`**. This is the study book: concepts, architecture diagrams, command tables with *why*, line-by-line YAML/HCL, and interview answers you hide and say out loud.

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080/devops-revision-interview.html](http://localhost:8080/devops-revision-interview.html).

How to sit: one topic → draw the architecture → type the commands in WSL without looking → Quiz mode → speak the answer → tick “I can explain this” only if that was true.

**Print notes:** click **Print notes** (or Ctrl+P). Use A4. Leave **Answers on paper** ticked for revision notes; untick it for a blank quiz printout. Filter a week first if you only want that chapter on paper.
